# 💰 Личный капитал (Wealth Manager)  
### *Умное веб-приложение для управления личными финансами и инвестициями*

---

## 🚧 Текущий статус проекта: **ИНИЦИАЦИЯ (Фаза 0)**
> **Важно:** Проект находится на стадии архитектурного проектирования и подготовки инфраструктуры.  
> На данный момент **не установлена операционная система**, не развернута виртуальная машина и не написана ни одна строка серверного кода.  
> Данный документ описывает **целевое видение** продукта и пошаговый план его создания с нуля.

---

## 1. Цель и назначение
Создать единое веб-окно для частного инвестора, позволяющее:
- Отказаться от Excel-таблиц для учета банковских счетов.
- Консолидировать данные по дебетовым, кредитным, накопительным, вкладам и инвестиционным счетам.
- Получать наглядную инвестиционную аналитику через прямое подключение к **Т-Инвестиции (T-Invest API)** без необходимости заходить в приложение брокера.

---

## 2. Техническая архитектура (План)
Проект строится по принципу **монолитного веб-приложения** для упрощения развертывания одним разработчиком.

| Компонент | Технология | Обоснование |
| :--- | :--- | :--- |
| **Гипервизор** | VMware Workstation 17 | Развертывание на локальной машине для полного контроля над средой. |
| **Операционная система** | Oracle Linux 9 (RHEL-совместимый) | Высокая стабильность, бесплатная лицензия, родная поддержка в VMware. |
| **Серверное окружение** | Python 3.9+ / Flask | Легковесность, прозрачность кода, идеально для старта. |
| **База данных** | SQLite (на старте) / PostgreSQL (в перспективе) | SQLite не требует отдельной установки и настройки на этапе MVP. |
| **Фронтенд** | HTML5 + Bootstrap 5 + Chart.js | Готовые компоненты UI для быстрой визуализации данных. |
| **Интеграция с брокером** | REST API (T-Invest) | Использование токенов доступа для получения портфеля и истории операций. |

---

## 3. Подробный план реализации (Roadmap)

Проект разбит на логические этапы. **Мы находимся прямо сейчас на Этапе №0**.

### 🟢 Этап 0: Подготовка инфраструктуры (Текущая задача)
- [ ] Скачать ISO-образ Oracle Linux 9.
- [ ] Создать виртуальную машину в VMware (CPU: 4 ядра, RAM: 8 ГБ, HDD: 100 ГБ).
- [ ] Установить ОС с настройкой сети (NAT/Bridged).
- [ ] Настроить базовый firewall (открыть порт 5000 для тестового доступа).
- [ ] Установить Git, Python3, Pip.

**Дедлайн:** 1 день.

---

### 🔵 Этап 1: Ядро приложения (Бэкенд + База данных)
- [ ] Разработка структуры БД (SQLite): Таблицы `users`, `accounts`, `tokens`, `portfolio_cache`.
- [ ] Реализация модуля аутентификации (Flask-Login):
    - Регистрация и вход по email/паролю.
    - Хеширование паролей (werkzeug.security).
- [ ] Создание базового шаблона страниц (Bootstrap).

**Результат:** Работающая страница входа и пустой дашборд.

---

### 🟡 Этап 2: Управление банковскими счетами (CRUD)
- [ ] Создание форм для добавления счетов (Дебетовые, Кредитные, Накопительные, Вклады, Инвестиционные).
- [ ] Отображение списка счетов в таблице на дашборде.
- [ ] Расчет суммарного капитала по всем счетам.
- [ ] Функция редактирования/удаления счетов.

---

### 🔴 Этап 3: Интеграция с T-Invest API (Сердце проекта)
- [ ] Реализация класса-обертки `TInvestAPI` для работы с REST-методами.
- [ ] Реализация страницы настроек для ввода и хранения токена доступа (с шифрованием).
- [ ] Получение списка брокерских счетов (`/user/accounts`).
- [ ] Получение структуры портфеля (`/portfolio`) с акциями, облигациями и фондами.
- [ ] Кэширование данных портфеля в БД для снижения нагрузки на API.

---

### 🟠 Этап 4: Аналитический дашборд (Визуализация)

- [ ] Расчет текущей и полной доходности (в % и валюте).
- [ ] График динамики изменения капитала за период (при наличии истории операций).

- [ ] Настройка обратного прокси (опционально, Nginx).

## 4. Функциональные требования (User Stories)

1.  **Как пользователь**, я хочу войти в систему по email и паролю, чтобы видеть только свои данные.
2.  **Как пользователь**, я хочу добавить свой дебетовый счет в Тинькофф и кредитку в Сбере, чтобы видеть общий баланс в одном месте.
3.  **Как пользователь**, я хочу ввести свой токен Т-Инвестиций один раз, чтобы приложение автоматически подтягивало мои акции.
4.  **Как пользователь**, я хочу видеть круговой график, чтобы понимать, сколько у меня в акциях, облигациях и деньгах.
5.  **Как пользователь**, я хочу нажать кнопку "Обновить", чтобы увидеть актуальную стоимость портфеля прямо сейчас.

## 5. Требования к окружению (Server Specs)
Для успешного запуска проекта необходима следующая инфраструктура (будет развернута на Этапе 0):

- **ОС:** Oracle Linux 9.x (Red Hat Compatible Kernel).
- **Пакеты:** `python3`, `python3-pip`, `git`, `firewalld`.
- **Сеть:** Статический IP-адрес в локальной сети (или NAT с пробросом портов).
- **Ресурсы:** Минимум 8 ГБ ОЗУ, 2 ядра CPU.

## 6. Риски и пути их решения

| Риск | Решение |
| :--- | :--- |
| **Незнание Python/Flask** | Изучение базового синтаксиса Python параллельно с разработкой (использование документации Flask). |
| **Сложность с T-Invest gRPC** | Переход на REST API (используя библиотеку `requests`), чтобы упростить интеграцию. |
| **Ошибки firewall/SELinux на Oracle Linux** | Тестирование на этапе MVP в режиме `permissive` для SELinux с последующей настройкой политик. |
| **Потеря данных** | Внедрение ежедневного бэкапа файла `database.db` через CRON-задачу. |
